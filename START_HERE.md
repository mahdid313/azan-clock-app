## ⚡ Quick Start (3 Steps)

### 1️⃣ Install Dependencies

```bash
npm install
```

### 2️⃣ Replace Placeholder Audio

Replace MP3 files in:
- `src/Azan/` (5 files)
- `src/Duas/` (26 files)  
- `src/Tasbeeh/` (4 files)

**Keep the same filenames!**

### 3️⃣ Build APK

```bash
npm run build
```

**Output:** `android/app/build/outputs/apk/debug/app-debug.apk`
